# SRNTV Launcher v1.0.0 — First Public Release

Initial public release of SRNTV Launcher featuring the Black & Red Liquid Glass theme, dynamic wallpaper system, and PriceDow typography integration.

**Features:**
- AMOLED Black interface.
- Liquid glass UI components.
- Dynamic crossfading wallpapers.
- Quick setting shortcuts for Inputs, Wi-Fi, and Settings.
- Android TV optimized navigation.

*Note: Due to licensing, wallpaper and font assets are not bundled. Please refer to README.md for setup instructions.*
